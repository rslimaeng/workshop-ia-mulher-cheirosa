M2 · Núcleo do Workshop

IA para Gestão

35 min · 86% da turma sofre com análise de dados e planilhas

Por que gestão é o núcleo

A dor que mais aparece nos dados

Na sondagem MC, 3 em 7 pessoas disseram que "analisar relatórios de vendas" é o que mais consome tempo. Outras 3 em 7 disseram "cruzar planilhas de clientes/serviços". Somando: 86% da turma sofre com o mesmo tipo de trabalho.

E a expectativa top da turma (4 em 7 votos) foi: "reduzir tempo em tarefas repetitivas". Esse bloco existe exatamente para isso.

O que você vai levar deste bloco: capacidade de sentar na frente de uma planilha e, em 5 minutos, extrair insight que hoje leva 1 hora. Não é mágica — é método.

Caso 1 · Análise de vendas

Comparar desempenho das 3 unidades

Você tem os números de Maison, RioMar FOR e RioMar Recife de junho. Vai apresentar para a Lilianne amanhã. Sem IA, isso leva 1h de análise + 30min de escrita. Com IA + PCTFL, 10 minutos.

1 Prompt PCTFL para análise comparativa

Cole seu recorte de dados (sem informações confidenciais). O prompt já vem estruturado:

Papel: Você é um consultor de operações de rede de serviços premium. Contexto: Trabalho na Mulher Cheirosa. Temos 3 unidades: Maison Aldeota (FOR, tradicional, rua desde 1987), RioMar Papicu (FOR, shopping) e RioMar Recife (PE, shopping). Cada uma tem perfil de cliente diferente. Tarefa: Com base nos dados abaixo: 1. Compare as 3 unidades em ticket médio, mix de serviços e frequência de retorno 2. Identifique qual unidade performa melhor em cada dimensão 3. Sugira 1 hipótese sobre a diferença 4. Recomende 2 ações específicas para a unidade de pior desempenho Dados: [cole o recorte da planilha aqui] Formato: - Tabela comparativa - Ranking por dimensão - Hipótese em 1 parágrafo - Ações com responsável e prazo Limitações: Considere que Maison é rua desde 1987 (base fiel), RioMar são shopping (fluxo maior de passagem). Não compare como se fossem operações idênticas. Não invente números.

O que sai: análise estruturada em formato de reunião, com hipóteses explicadas e ações prontas para virar tarefa. Você chega na reunião com interpretação, não com planilha crua.

Caso 2 · Cross-sell de clientes

Cruzar clientes × serviços para achar oportunidade

Toda cliente que faz Banho de Lua é potencial cliente de Spa da Noiva ou Cronograma Capilar. Mas você não tem tempo de olhar cliente por cliente. A IA olha por você — se você pedir direito.

2 Prompt para identificar oportunidade de venda cruzada

Papel: Você é um analista de CRM especializado em clínicas de beleza premium. Contexto: Trabalho na Mulher Cheirosa. Tenho uma base de clientes que fizeram Banho de Lua no último trimestre e queria entender oportunidades com Spa da Noiva, Micropigmentação e Cronograma Capilar. Tarefa: Com base nos dados abaixo: 1. Perfil das clientes que fizeram só Banho de Lua (idade, frequência, ticket médio) 2. Quais características apontam propensão a Spa da Noiva 3. 3 mensagens personalizadas para diferentes perfis 4. Qual segmento tem melhor custo/benefício para começar Dados: [cole recorte simples: nome, idade, serviço, data, valor] Formato: - Perfil resumido - Tabela: perfil × propensão × justificativa - 3 mensagens completas - Recomendação em 2 linhas Limitações: Só use dados fornecidos. Não invente comportamentos. Mensagens no tom MC: sofisticado, acolhedor, feminino.

O que sai: lista curta de clientes com potencial de recompra, mensagem escrita e pronta para o time de atendimento disparar. Deixa a IA fazer o trabalho de garimpo — você decide a estratégia.

Caso 3 · Relatório executivo

De dados brutos para reunião com a diretoria

Reunião amanhã de manhã com a Lilianne. Você tem números soltos, situações pontuais e algumas preocupações. Precisa transformar isso em 1 página que alguém que tem 5 minutos consegue ler.

3 Prompt para relatório executivo de 1 página

Papel: Você é um analista de gestão que escreve relatórios executivos para diretoria de PMEs premium de serviços. Contexto: Sou coordenadora da Mulher Cheirosa. Preciso apresentar o resultado de junho para Lilianne Veloso em uma reunião rápida amanhã. Vou apresentar em 5 minutos. Tarefa: Com base nos dados brutos abaixo, estruture um relatório executivo de 1 página. Foque no que a diretoria precisa saber para decidir, não em detalhe operacional. Dados brutos: [cole números, situações, problemas] Formato: - Título e período - Resumo executivo (3 linhas: o que aconteceu, resultado, o que está em risco) - Tabela das 3-5 métricas principais com variação vs mês anterior - Pontos de atenção (máximo 3) - Recomendação ou próximos passos Tom: direto, sem rodeios. Quem lê tem 5 minutos. Limitações: Use apenas dados fornecidos. Se faltar dado essencial, avise antes de concluir. Não invente comparações históricas.

O que sai: relatório de 1 página, formato reunião, que Lilianne consegue ler no elevador subindo. Você chega preparada, não apagando incêndio.

Antes de sair correndo

Limitações que você precisa saber

Ferramenta gratuita tem limite. Aqui está o que cada versão faz:

Recurso ChatGPT Gratuito ChatGPT Pago / Claude Pro
Colar recorte de dados no chat Funciona Funciona
Upload de Excel completo Limitado (só web, versão nova) Funciona bem
Analisar planilha grande (>1000 linhas) Não recomendado Funciona
Criar assistente personalizado (MC padrão) Não Sim (MyGPTs, Claude Projects, Gems)
Salvar contexto entre conversas Parcial Completo

Para hoje: vamos trabalhar com recortes de planilha colados no chat. Isso funciona em qualquer versão. Se você tem a versão paga, aproveita para testar upload no exercício.

Segurança: não cole dados de clientes com nome completo, CPF ou telefone em conta pessoal de IA. Use iniciais ("Cliente M.V.C.") ou apelidos genéricos. Dados financeiros da MC (faturamento, margem por unidade) só em ferramenta corporativa autorizada — nunca em conta pessoal gratuita.

Exercício em dupla · 15 min

Sua análise de vendas em 10 minutos

Cada dupla pega o recorte de dados MC disponível na página de artefatos. Aplique o prompt do Caso 1 (análise comparativa) e produza a análise executiva.

  1. Baixe o recorte de dados — planilha fictícia com vendas das 3 unidades de junho.
  2. Cole no ChatGPT ou Claude — junto com o prompt do Caso 1.
  3. Leia o resultado — o que a IA identificou? Faz sentido? Onde está fraco?
  4. Refine o prompt — o que precisa ajustar em Contexto, Tarefa, Formato ou Limitações?
  5. Rode de novo — melhor?
  6. Compartilhem — 2 duplas apresentam em 30s cada.

Meta: sair deste bloco com 1 análise executiva pronta baseada em dados reais, feita em 10 minutos, que você já pode adaptar para levar amanhã para reunião.
